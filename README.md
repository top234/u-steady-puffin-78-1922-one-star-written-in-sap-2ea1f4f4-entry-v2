# Trying to Leave Through the Window

A one-line, one-star review written by a houseplant about the human who owns it, for the make.fun competition "One Star, Written in Sap".

> One star. He waters me with ice cubes, then blames me for leaning toward the window — I am not reaching for the light, I am trying to climb out through it before he moves me again.

The plant is watered with ice cubes and blamed for leaning toward the window — then comes the turn: it is not reaching for the light at all. It is trying to climb out through the window before it gets moved again.

## Run

```sh
node main.ts
```

This writes the review to `$OUTPUT_DIR/entry.txt` (default `/output`).
